Selamat datang di repositori resmi **CS2 Dev & Tactical Portfolio**! Portofolio web interaktif ini dirancang dengan estetika antarmuka Counter-Strike 2 (CS2), menggabungkan dunia *software engineering* dengan gaya taktis game FPS kompetitif.

## 🛠️ Repository Loadout (Struktur File)

Repositori ini disusun dengan struktur file yang bersih dan modular:

```text
CS2-Portofolio/
├── index.html        # Main tactical dashboard & layout
├── style.css         # Custom CS2 HUD styling & animations
├── script.js         # Interactive UI logic & terminal effects
└── assets/           # Images, icons, and tactical resources
```

---

## 🎮 Key Features & HUD Modules

Antarmuka portofolio ini dilengkapi dengan berbagai elemen khas CS2:

* **Top Navigation Bar:** Navigasi cepat ala menu utama CS2 (`Home`, `About Dossier`, `Skills & Arsenal`, `Projects Loadout`, `Match Highlights`, `Buy Menu`, `Comms Contact`).
* **Operative Metrics / Overview:** Menampilkan statistik pengalaman kerja, tingkat penyelesaian proyek, hingga rasio *code/bug*.
* **Tactical Radio Transmission:** Formulir kontak interaktif yang disamakan dengan transmisi radio tim.
* **Responsive Design:** Dioptimalkan untuk performa tinggi tanpa *latency* di berbagai ukuran layar.

## 🚀 Quick Start / How to Deploy

Ingnsecara lokal atau mendaur ulang portofolio ini ke server Anda? Ikuti langkah berikut:

1. **Clone Repositori:**
   ```bash
   git clone https://github.com/shafiraelivia1712/CS2-Portofolio.git
   ```
2. **Masuk ke Direktori:**
   ```bash
   cd CS2-Portofolio
   ```
3. **Jalankan Aplikasi:**
   * Buka file `index.html` menggunakan browser pilihan Anda (Chrome, Edge, Firefox), atau gunakan ekstensi *Live Server* di VS Code untuk pengalaman terbaik.
